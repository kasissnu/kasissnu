## Key Projects

### Aether: Dynamic Island for macOS
**Native macOS Utility** | Dynamic Island-Inspired System Experience | **Repository**: [GitHub](https://github.com/kasissnu/aether)

Aether turns the top of your Mac display into a native Dynamic Island-style notch with fast media controls, live playback state, Bluetooth/AirPods battery, Mac battery, volume activity, shelf actions, fullscreen-aware behavior, and low-overhead refresh logic.

**Key Features:**
- Native Dynamic Island-style notch for macOS
- Media activity with artwork, progress seeking, play/pause, previous/next, shuffle, and repeat
- Low-overhead Now Playing integration with optional Spotify, Apple Music, and YouTube Music controllers
- AirPods-style Bluetooth battery status with layered fallbacks
- Mac battery and volume live activity
- Fullscreen-aware hiding and multi-display placement options
- Adaptive polling and event-driven refresh paths to reduce idle CPU and battery usage
- Packaged releases with one-line install/update script

**Tech**: Swift, macOS, Native App Development, Now Playing, Apple Events, CoreAudio, Bluetooth, App Packaging

### Grayd: AI Learning Platform Backend
**Production-Oriented RAG Backend** | AI Study Platform Architecture | **Repository**: [GitHub](https://github.com/kasissnu/grayd_backend)

Grayd is a FastAPI backend for an AI-powered learning platform. It supports document ingestion, course and notebook management, file indexing, streaming AI responses, and Retrieval-Augmented Generation over uploaded study material.

**Key Features:**
- RAG over user-uploaded study material
- Streaming AI responses using Server-Sent Events
- Context-aware retrieval scoped by course, notebook, file, topic, or page range
- Query handling for teaching, summaries, revision, planning, comparisons, and question generation
- Background indexing worker for asynchronous document processing
- Chunking, embedding generation, reranking, and Qdrant vector storage
- Supabase Storage integration with signed upload/download flows
- Clerk JWT authentication and user-specific resource ownership checks
- Model-role routing for reasoning, summarization, OCR, query understanding, and teaching

**Tech**: FastAPI, Python, RAG, Qdrant, Supabase, Gemini, Cohere, LangChain, Clerk, SSE, Pydantic

### Edipik: AI Photo Editing Platform
**Full-Stack AI/CV Platform** | Image Processing + Real-Time Backend | **Repositories**: [Frontend](https://github.com/kasissnu/edipik_frontend) · [Backend](https://github.com/kasissnu/edipik_backend)

Edipik is a full-stack AI-powered photo editing platform with a React frontend and Django REST backend. It handles image uploads, authentication, AI/CV workflows, asynchronous processing, cloud storage, and real-time communication.

**Key Features:**
- Django REST backend for AI photo editing workflows
- React frontend integration
- Google authentication and JWT support
- Image-processing and computer-vision pipeline support
- Celery + Redis for long-running asynchronous tasks
- Django Channels/WebSockets for real-time updates
- AWS/S3 integration for image asset storage
- MySQL-backed application data
- TensorFlow, Keras, Torch, OpenCV, and related ML/CV tooling

**Tech**: React, Django REST Framework, Celery, Redis, Django Channels, WebSockets, AWS/S3, MySQL, OpenCV, TensorFlow, PyTorch

### Memora: AR-Based Cognitive Assistive Platform
**Assistive AI Concept** | AR + Computer Vision + Memory Support | **Repository**: [GitHub](https://github.com/kasissnu/alzheimer)

Memora is an AR-based cognitive assistive platform concept designed to support early-stage Alzheimer's patients. It explores how augmented reality, facial recognition, age-progression-tolerant identity matching, lifelong learning, and voice-based NLP prompts can help users recognize familiar people and recall important context.

**Key Features:**
- Face recognition for familiar-person identification
- Contextual memory cues such as name, relationship, notes, and recent interactions
- Age-progression-tolerant recognition concept
- Lifelong learning for updating known face profiles and relationship context
- Voice-based NLP prompts for natural interaction
- AR-based visual memory cues designed for low cognitive load

**Tech**: AI/ML, Computer Vision, Face Recognition, AR, NLP, OpenCV, MediaPipe, DeepFace, FastAPI, Vector Databases
